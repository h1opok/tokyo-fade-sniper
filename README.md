## ⚡ Ключевые особенности
- **Стратегия Fade:** Вход в сделку только после отката (exhaustion) от локального экстремума (pump/dump > 1.2%).
- **Умный риск-менеджмент:** Фиксированный риск на сделку (по умолчанию 3%), автоматический расчет размера позиции (Notional) с учетом плеча 10x.
- **Trailing Stop:** Активируется при +0.6% прибыли, подтягивая стоп-лосс, чтобы зафиксировать прибыль и превратить потенциальные убытки в безубыток.
- **Оптимизация комиссий:** Использование лимитных ордеров `GTX` (Post-Only) для гарантированного получения Maker-комиссии (0.02% или 0.00% с BNB).
- **Защита от просадок:** Жесткий дневной лимит убытков (Daily Loss Limit). При достижении лимита бот автоматически останавливает торговлю до следующего дня.
- **Белый список активов:** Торговля ведется только по 20 тщательно отобранным, высоколиквидным парам (SOL, NEAR, INJ, SEI и др.), прошедшим количественную валидацию.
